# Адаптеры календарей

Три скрипта, которые забирают официальные календари и выдают TSV.
Только `sh`, `curl` и `awk` — работают на телефоне без Python и Node.

```sh
sh agr.sh    > agr.tsv      # 37 турниров, АГР (Россия)
sh baf.sh    > baf.tsv      #  9 турниров, Белорусская ассоциация гольфа
sh golfru.sh > golfru.tsv   #  5 турниров, ГОЛЬФ.РУ
```

## Колонки

| Файл | Колонки |
|---|---|
| `agr.tsv` | месяц таба · даты как на сайте · название · место · код · организатор |
| `baf.tsv` | start · end · «дата • длительность • место» · название · «вид • категории» |
| `golfru.tsv` | дата `дд.мм.гггг` · название · путь карточки |

## Как TSV превращается в `data/golf-data.js`

1. Даты с АГР («8-11 апреля», «31 мая – 6 июня», «24–25 сентября») переводятся
   в ISO с годом 2026: первая часть даёт `start`, вторая — `end`; если месяц
   во второй части не указан, он наследуется.
2. У БАГ `start`/`end` уже в ISO в разметке; для событий длиной «1 день»
   `end` приравнивается к `start` (в `data-end` сайт пишет следующий день).
3. У ГОЛЬФ.РУ дата `дд.мм.гггг` — один день, `end = start`; место на сайте
   не указано, поэтому `location: "уточняется"`.
4. Каждой записи добавляются `source`, `sourceName`, `origin: "parsed"`,
   `extractedAt` — чтобы в приложении было видно, откуда факт и когда снят.
5. Статус не сохраняется: приложение считает его из дат, поэтому он не устаревает.

## Ограничения

- Разбираются только те страницы, где есть структура (таблица, карточки, список).
- `robots.txt` проверен: у АГР `Allow: /`, у ingolf.by общие страницы разрешены,
  у golf.ru контент разрешён (закрыты форум, поиск, `/bitrix/`).
- Победители, счёт и условия участия не собираются: без официального протокола
  их добавлять нельзя.
- Скрипты не запускаются по расписанию — это ручной снимок. Даты на сайтах
  меняются, поэтому перед поездкой нужна сверка с первоисточником.
