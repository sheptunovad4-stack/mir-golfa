## Что ещё добавлено

**Проверка сайтов** — 186 уникальных адресов из реестра источников и клубов
(сайты, Telegram, VK, Instagram). Для каждого записан код ответа, адрес после
редиректов, заголовок страницы и описание. Результат от 22 ноября 2026:

- 120 — отвечают (HTTP 200)
- 5 — редирект
- 5 — ошибка 403
- 5 — ошибка 404
- 1 — ошибка 500
- 1 — файл (документ, не страница)
- 54 — нет ответа (таймаут или блокировка)

Это разовая проверка главных страниц, а не сбор турниров. Она показывает,
какие источники живые, а какие стоит заменить.

## Структура `data/golf-data.js`

```js
window.GOLF = {
  meta:    { exported, checked, sources, clubs, archive, checks },
  events:  [ ... ],   // турниры (демо-календарь)
  sources: [ { n, name, country, region, type, roles, owner, status, channel, url, note } ],
  clubs:   [ { n, country, region, name, type, site, telegram, social, channelStatus, note } ],
  archive: [ { n, name, url, category, reason } ],
  checks:  [ { url, code, final, title, desc } ]
};
```

Файл подключается в `index.html` тегом `<script src="data/golf-data.js">`,
поэтому страница работает и на GitHub Pages, и локально без сервера.

## Что осталось за кадром

В таблице есть тип источника и роли («календарь», «результаты», «регистрация»),
но нет самих турниров и результатов. Автоматического разбора страниц пока нет:
он требует отдельных адаптеров под каждый сайт и проверки `robots.txt`.
До этого данные в приложении остаются демонстрационными, с ручной сверкой.
