# Ежедневный монитор источников

Это первый рабочий слой сбора: он проверяет страницы из `sources.json`, соблюдает `robots.txt`,
сохраняет отпечатки страниц и найденные ссылки в SQLite, а изменения ставит в очередь проверки.
Он **не извлекает автоматически победителей/счёт** и не публикует статьи — это намеренно, пока
не сделаны специфические парсеры и проверка первоисточников.

## Установка
```bash
pip install -r requirements.txt
python -m app.collectors.monitor
```

Из корня `backend`. Для ежедневного расписания:
```bash
python -m app.collectors.scheduler
```

Настройки:
- `GOLF_CIS_SOURCES` — путь к JSON реестру источников.
- `GOLF_CIS_MONITOR_DB` — путь к SQLite файлу.
- `GOLF_CIS_RUN_HOUR` / `GOLF_CIS_RUN_MINUTE` — расписание по Москве.
- `GOLF_CIS_USER_AGENT` — укажите честный User-Agent и контакт администратора.

Перед продакшеном: проверить условия использования сайтов, использовать официальные API/RSS, настроить
лимиты запросов, мониторинг, резервное копирование и отдельные адаптеры для каждого источника.
